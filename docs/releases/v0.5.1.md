# 中国法律智能体 v0.5.1

发布日期：2026-10-15。

## 任务投递延迟

后台投递器每轮扫描结束后的等待间隔从 2 秒缩短至 0.2 秒，减少提交后等待进入 Redis 队列的时间。任务仍先保存到 PostgreSQL，投递失败时保留待投递标记，后续扫描重试。该调整不改变 Redis 持久化、Worker 执行方式或业务重试逻辑。

## 法律检索测评

- 有标题用例由 130 条扩充至 300 条，覆盖 240 个不同法条；新增 170 条目标均在本地法律库核验，原有 200 条用例保持不变。
- 主数据集共 370 条，保留的 70 条无标题用例不参与本轮测评。
- 固定路径为标题 BM25 最高分并列候选 → 正文 BM25 前 50 条 → BGE 重排前 5 条，不调用向量检索或 Embedding API。
- BM25 候选 Recall@50：100%（300/300）；重排后 Recall@1：94%（282/300）；Recall@5：99.67%（299/300）；MRR：0.9678。
- 唯一未进入重排前五的目标为《民法典》第五百一十一条，其正文 BM25 原排第一。本轮没有根据检索结果调整问题或预期答案。

测评使用人工预设标题与关键词，按法规标题＋条号计分，不衡量自动选法、版本适用性或最终答复准确率。详见 [数据与复现说明](../../evals/README.md) 和 [测评报告](../../eval-results/legal-retrieval-titled-300-bm25-rerank.md)。

## Docker Hub

本版为 linux/amd64，同时发布版本标签 `0.5.1` 和 `latest`：

- `sysoe/chinese-legal-agent`：API、Worker。
- `sysoe/chinese-legal-agent-init`：资源初始化。
- `sysoe/chinese-legal-agent-web`：网页前端。

部署使用 [compose.release.yaml](../../compose.release.yaml)。现有用户更新 Compose 文件后执行 `docker compose -f compose.release.yaml pull` 和 `docker compose -f compose.release.yaml up -d --wait`。无需重新导入法律库或删除数据卷。
