# 中国法律智能体 v0.5.2

发布日期：2026-10-19。

## 法律分析与追问

- 法律子图保存历史追问，并将历史问题、用户补充和已总结的客观事实传给决策节点。决策结合检索到的法律判断是否需要补充关键事实，避免重复询问已经问过的问题。
- 新增不确定性回答节点。已追问但仍无法确定、且会影响结论的事实，由决策节点记录为不确定点；回答节点接收与普通最终回答相同的结构化上下文，说明已知结论及不同事实条件下的判断。
- 不确定性回答仍须使用已检索并确认可用的法律依据；没有有效法律依据时保留拒答路径。

## Agent 对照评测

README 增加项目定位与简洁对照图，展示 [A v3 固定工作流](../../comparison/reports/A_v3.md) 和 [B v1 无工作流 Agent](../../comparison/reports/B_v1.md) 的结果。两组均使用 DeepSeek flash，每组 36 次：

| 指标 | A v3 | B v1 |
| --- | --- | --- |
| 答案语义通过 | 36/36 | 22/36 |
| 必须追问场景实际追问 | 18/18 | 4/18 |
| 平均 Agent Token | 30,122.92 | 56,275.53 |
| 平均耗时 | 57.348 秒 | 22.045 秒 |

模拟用户依据预设事实由 LLM 理解问题后回答；模拟用户和评分模型的 Token 不计入 Agent 指标。B v1 汇总既有记录与单案补测，耗时不构成完整连续执行的严格速度对照。12 个案件已用于调试，语义通过率不代表泛化准确率或零法律幻觉。

## Docker Hub

三个业务镜像均发布 `linux/amd64` 的 `0.5.2` 和 `latest` 标签：

- `sysoe/chinese-legal-agent`：API、Worker。
- `sysoe/chinese-legal-agent-init`：资源初始化。
- `sysoe/chinese-legal-agent-web`：网页前端。

使用本版本的 [compose.release.yaml](../../compose.release.yaml)，在现有部署目录备份数据并更新 Compose 文件后执行：

```powershell
docker compose -f compose.release.yaml pull
docker compose -f compose.release.yaml up -d --wait
```

无需重新导入法律库或删除数据卷。部署要求与配置步骤见 [Docker Hub 部署说明](../dockerhub-release.md)。
